# Qiskit Fall Fest 2026

Solutions and notebooks for the **Qiskit Fall Fest 2026** challenges.

## 📁 Repository Structure

- `Challege 1.ipynb`: Challenge 1 Notebook
- `Challenge 2.ipynb`: Challenge 2 Notebook
- `Challenge 3.ipynb`: Challenge 3 Notebook
- `Challenge 4.ipynb`: Challenge 4 Notebook

## 🚀 Setup & Requirements

To run these notebooks locally, install the necessary dependencies:

```bash
pip install qiskit qiskit-aer matplotlib jupyterlab
```

Run JupyterLab or Jupyter Notebook:

```bash
jupyter lab
```
